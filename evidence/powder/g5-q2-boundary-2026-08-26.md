# POWDER G5 RF Calibration — Q2 Boundary Result

Date: 2026-08-26 (Cairo)
Experiment: WP-G5-RF-CAL
Purpose: non-scored boundary calibration between stable Q1 and effective-outage Q3.

## Tested attenuation windows
All four RFLink attenuator IDs (1, 33, 2, 34) were set together for ~20 s at each point, with recovery to 0 dB between tests.

Observed application ping behavior:
- +42 dB: 0 replies, 20 misses, longest miss streak 20
- +44 dB: 0 replies, 19 misses, longest miss streak 19
- +46 dB: 0 replies, 20 misses, longest miss streak 20
- +47 dB: 0 replies, 20 misses, longest miss streak 20

Prior evidence established +40 dB as continuously connected under sustained ping, with approximately -100 dBm RSRP and ~18–19 dB SNR.

## Interpretation
The transition from continuously connected to effective application-data outage is extremely sharp and is bounded between +40 and +42 dB additional attenuation under this conducted path and runtime state.

The only remaining integer attenuation value inside that boundary is +41 dB. Therefore +41 dB is the sole unresolved integer candidate for Q2 (near-threshold/intermittent). If +41 dB remains continuously connected, there is no integer-valued static attenuation point that satisfies the Q2 semantic definition and Q2 must be implemented by a reproducible time-varying schedule or by a finer supported attenuator step, subject to explicit protocol amendment before scoring. If +41 dB produces a full-window outage, the same conclusion applies.

No scored-run authorization is implied by this evidence.
