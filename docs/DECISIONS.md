# Decision Register

## D-001 — Validation order
FIT IoT-LAB is the first remote-testbed layer. ARA is conditional on a successful FIT result. NITOS and POWDER remain hold/backup only.

## D-002 — Smallest publishable experiment
Freeze WP-RT01 around the existing 10,000-record outage/restart hypothesis rather than inventing extra testbed experiments.

## D-003 — Baseline
Compare durable offline-first behavior with a publish-only/non-durable baseline so the experiment measures an architectural effect rather than merely demonstrating that software runs.

## D-004 — No evidence inflation
Remote networking evidence is not pump, hydraulic, groundwater, agronomic, or Siwa field evidence.

## D-005 — No ARA BYOD initially
Use existing ARA compute/network resources first if WP-RT01 passes; custom hardware shipping is deferred unless it becomes necessary for a material claim.
